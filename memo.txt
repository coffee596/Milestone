# ==========================================
# 開発サーバーの起動と終了
# ==========================================

■ サーバーを起動する
npm run dev

■ サーバーを停止する（ターミナル上で実行）
Ctrl + C
（その後に Y を押して Enter）

■ 「ポート3000が使用中」で起動できないとき
VS Codeのターミナル右側にある「ゴミ箱アイコン（Kill Terminal）」を押して、ターミナルを完全に閉じてから開き直す。


# ==========================================
# コードを更新してGitHubに公開する（自動更新）
# ==========================================

VS Codeでファイルを保存（Ctrl + S）した後、ターミナルで以下の3つのコマンドを上から順番に実行する。

1. 変更したファイルをすべて登録する
git add .

2. 変更内容のメモを記録する
git commit -m "コードを更新"

3. GitHubにアップロードして公開サイトを自動更新する
git push origin main
